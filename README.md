# Fresh Decor — мини-приложение Telegram 

Каталог декора для аренды. Клиент листает каталог, нажимает «Уточнить»,
открывается чат с менеджером с готовым сообщением.

## Что внутри 

```
arenda_freshdecor/
├── index.html          ← мини-приложение (главная)
├── styles.css
├── app.js
├── logo.png            ← твой логотип
├── data.json           ← каталог (обновляется парсером)
├── build_catalog.py    ← парсер таблицы → JSON
├── AppsScript.gs       ← скрипт для Google Sheets (фото)
├── bot.py              ← Telegram-бот
├── requirements.txt
└── README.md
```

ВСЕ файлы лежат в **корне** репозитория. Никаких подпапок.

# Часть 1. Создаём репозиторий с чистого листа

## 1.1. Новый репозиторий

1. github.com → "+" → **New repository**
2. Имя: `arenda_freshdecor` (важно — это в URL приложения)
3. **Public**
4. Create repository

## 1.2. Загружаем файлы

На странице пустого репозитория → **uploading an existing file**.

Распакуй архив `fresh_decor.zip` → открой папку → **выдели всё внутри** (Cmd+A) → перетащи в браузер. **Не саму папку — только её содержимое!**

⚠ Скрытые файлы (`.gitignore`) GitHub при перетаскивании игнорирует. Их добавим вручную через "Add file → Create new file" (если понадобится).

Нажми **Commit changes**.

После загрузки на главной должны быть видны:
```
index.html  styles.css  app.js  logo.png  data.json
build_catalog.py  AppsScript.gs  bot.py  requirements.txt  README.md
```

# Часть 3. Apps Script — автозаполнение фото

Это главное изменение: фото будут подтягиваться **автоматически прямо в твоей таблице**.

## 3.1. Открываем редактор скриптов

1. Открой свою таблицу в Google Sheets
2. Меню **Расширения → Apps Script**
3. Откроется редактор кода

## 3.2. Вставляем скрипт

1. В редакторе будет файл `Code.gs` с пустой функцией — **удали всё содержимое**
2. Открой файл `AppsScript.gs` из репозитория (или из архива) — **скопируй весь код**
3. Вставь в редактор Apps Script (Cmd+V)
4. Нажми иконку **дискеты** сверху (или Cmd+S) — сохранить

## 3.3. Первый запуск (даём разрешения)

1. В выпадающем списке функций сверху выбери **`onOpen`**
2. Нажми **Run** (▶)
3. Появится окно «Authorization required» → **Review permissions**
4. Выбираешь свой Google-аккаунт
5. Появится экран **«Google hasn't verified this app»** — это нормально (твой скрипт, не из магазина)
   - Нажми **Advanced** внизу слева
   - **Go to Untitled project (unsafe)**
6. Нажми **Allow** на всех правах (доступ к таблице и Drive)

## 3.4. Возвращаемся в таблицу

Открой свою таблицу заново (или обнови вкладку F5).

В меню сверху должна появиться новая кнопка **🌿 Fresh Decor**. Если её нет — обнови страницу ещё раз через 5 секунд.

## 3.5. Запускаем первый раз

1. **🌿 Fresh Decor → Настроить заголовок колонки N** — это создаст шапку в N1 «Фото URL»

2. **🌿 Fresh Decor → Обновить фото (только новые)** — пройдётся по всем товарам и заполнит колонку N

Появится зелёное уведомление внизу: «Обработано: 126, обновлено: 90...»

В колонке N появятся ссылки вида `https://drive.google.com/uc?export=view&id=...`

⚠ Apps Script даёт **6 минут на один запуск**. Если у тебя 200+ товаров — скрипт может не успеть за один раз и сам остановится с пометкой в логе. Просто запусти его повторно — он продолжит с того места, где остановился (пропустит уже заполненные ячейки).

## 3.6. Включаем автообновление

**🌿 Fresh Decor → Установить автозапуск (раз в час)**

Теперь раз в час Apps Script сам будет проверять новые товары (без фото) и добавлять им ссылки.

# Часть 4. Парсим таблицу → data.json

Apps Script заполнил колонку N. Теперь Python-скрипт прочитает таблицу и сделает `data.json`, который читает мини-приложение.

## 4.1. Локально

Открой Терминал на Маке:

```
cd ~/Downloads/fresh_decor   (или куда распаковала архив)
python3 build_catalog.py
```

Должна увидеть:
```
Прочитано строк: ~~~
Обработано товаров: ~~~
Категорий: 4
Забронировано: ~~~
```

В папке появится обновлённый `data.json`.

## 4.2. Загрузи data.json на GitHub

Замени файл `data.json` в репозитории на свежий (Add file → Upload files → перетащи → Commit).

Через 1-2 минуты приложение покажет все товары с фото.

# Часть 5. Бот (опционально, для кнопки в Telegram)

Бот нужен только для того, чтобы у пользователя в Telegram была команда `/start`, которая откроет каталог.

## 5.1. Создай бота в @BotFather

1. В Telegram найди **@BotFather**
2. `/newbot` → имя → username (заканчивается на `bot`)
3. Сохрани токен

## 5.2. Запуск на render.com (бесплатно)

1. render.com → регистрация → **New → Background Worker**
2. Подключи свой GitHub-репозиторий `arenda_freshdecor`
3. Build Command: `pip install -r requirements.txt`
4. Start Command: `python bot.py`
5. Environment → добавь две переменные:
   - `BOT_TOKEN` = твой токен от BotFather
   - `WEBAPP_URL` = `https://polugore.github.io/arenda_freshdecor/`
6. **Deploy**

Через минуту бот живой — пиши ему `/start`, появится кнопка «Открыть каталог».

## 5.3. Привяжи приложение к меню бота

Чтобы каталог открывался не только по `/start`, но и по постоянной кнопке внизу:

1. **@BotFather → /mybots → выбери бота → Bot Settings → Menu Button → Configure menu button**
2. Имя: «Каталог»
3. URL: `https://polugore.github.io/arenda_freshdecor/`

# Что происходит дальше (рабочий день)

Когда добавляешь товар:

1. Добавила строку в таблицу — заполнила A-M
2. Через час Apps Script сам впишет URL фото в колонку N
3. Раз в день (или по желанию) — запускаешь `python3 build_catalog.py` локально → загружаешь `data.json` на GitHub
4. Через минуту товар появляется в приложении

Если хочешь сразу — запускаешь Apps Script вручную (🌿 Fresh Decor → Обновить фото), потом локальный скрипт. Полчаса дела.

## Будущее улучшение (необязательно)

Можно настроить GitHub Actions чтобы он сам раз в день запускал `build_catalog.py` — тогда вообще ничего делать не нужно будет. Скажешь когда захочешь — настроим.
