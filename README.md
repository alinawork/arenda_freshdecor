# Fresh Decor — обновление дизайна для GitHub

В архиве находятся только файлы интерфейса и визуальные материалы. Код бота и данные каталога сюда не включены.

## Что заменить в репозитории

Загрузите эти файлы и папку в корень вашего GitHub-репозитория с заменой существующих версий:

- `index.html`
- `styles.css`
- `app.js`
- `build.mjs`
- `logo.png`
- папку `assets`

Папка `assets` должна находиться рядом с `index.html`. В ней лежат два новых шрифта и семь фотографий категорий.

## Что не трогать

Сохраните без изменений:

- `data.json`
- `bot.py`
- `AppsScript.gs`
- `build_catalog.py`
- папку `.github`
- остальные файлы бота, каталога и автоматического обновления товаров

После загрузки файлов запустите существующую публикацию GitHub Pages или ваш обычный workflow, если он не запускается автоматически.
